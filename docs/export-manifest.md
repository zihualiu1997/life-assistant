# 独立仓库提取范围

仅提取通用实现，不复制原个人仓库的 Git 历史、配置或资料目录。

| 路径 | 来源及处理 |
| --- | --- |
| `server/life_assistant.py` | 原日记写入工具中的原子保存、文件锁及消息去重；去掉个人工作区和运行凭据依赖 |
| `server/life_service/` | 原简报模型、资料选择、SMTP 与持久调度；通用化设置、称呼、路径，首版禁用健康设备 |
| `server/openweather_sync.py` | 原 OpenWeatherMap 五天三小时预报处理；改为服务器凭据、可选城市及时区 |
| `server/life_app/` | 新的管理与设备权限、设置向导、知识库接口及设备对话桥接 |
| `openclaw-bridge/` | 新的限定工具与当前消息来源桥接；使用独立网关配置 |
| `desktop/src/` 与 `desktop/src-tauri/` | 基于原 Tauri 交互重新整理的服务器客户端；仅保存设备连接凭据 |
| `desktop/assets/pet.webp` 与桌面图标 | 项目所有者已确认允许复用的资源；具体声明见根目录第三方说明 |
| `tests/` | 临时目录和虚构测试数据，不读取原用户笔记或账号 |
| `gateway/`、安装器、`scripts/`、`.github/`、文档与许可证 | 新的独立部署与发布材料 |

自动创建的知识库只有必要索引和空白模板。个人路径、邮件账户、聊天历史、真实日程、设备数据、API Key、日志及本机设置不属于提取范围。

服务器归档由 `scripts/build_release.py` 中的白名单生成。发布检查分别扫描源码、服务器归档、Windows 二进制、安装器及安装器解包内容。正则扫描不能证明不存在全部类型的私人资料，公开前还应按本清单人工复核。
