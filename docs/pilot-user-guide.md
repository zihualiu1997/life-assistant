# 私人助手内测开通说明

这份说明供受邀测试者使用。当前版本仍在验收，只有运营者通知开始真实账号测试后，才进行扫码和邮件验证。每个人使用独立网址和空间；暂不支持自行注册。网页用于开通、设置、管理资料和查看用量，日常聊天使用微信。

## 第一次开通

1. 用普通浏览器打开运营者私下发给你的 HTTPS 网址，输入一次性开通凭据，设置至少 12 个字符的密码，点击“开通／登录”。凭据 30 分钟有效、只能使用一次；过期请让运营者重新生成。以后用自己的密码登录同一网址。
2. 打开“记忆与隐私偏好”，填写称呼和时区，分别决定是否允许云端处理、自动整理、主动联系，点击“保存偏好”。云端处理未开启时，模型、语音识别和微信助手不能正常启用。可以先只开启云端处理，之后再决定其余两项。
3. 回到首页，在“邮箱验证”中填写自己的邮箱，点击“发送验证码”，从实际收到的邮件中取出验证码，点击“验证邮箱”。验证码十分钟有效。没有收到时先检查垃圾邮件，不要把页面的“已提交”当作收到。
4. 点击“扫码连接微信”，稍后点“刷新连接状态”，使用自己的微信扫描二维码并确认。登录完成后点击“登录完成，启动助手”，在微信发一条测试消息。二维码、开通凭据和密码不要转发给他人。
5. 点击“测试模型”和“发送测试邮件”。亲自检查邮箱，再依次生成“预览晨报”“预览晚报”。确认两份内容后勾选实际收件和预览同意，点击“启用简报”。默认晨报 08:30、晚报 21:00，按个人时区运行；修改相关设置后需重新检查预览。

运营者统一提供模型和发件服务，你无需填写供应商密钥或 SMTP 密码。开通遇到错误时，把发生时间、操作和页面错误文字告诉运营者，不发送密码、验证码或二维码。

## 微信怎么用

- 可以发送文字、图片和语音，助手以文字回复。视频、复杂附件、语音通话和语音回复暂不支持。
- 明确要记日记时说“记一下：……”，并检查助手给出的落盘回执。没有回执或提示失败时，不要认定已保存。
- 连续补充同一件事时，文字默认等待 3 秒，包含媒体时等待 20 秒后合并处理。也可以单独发送“等我发完”，补充结束后单独发送“发完了”；放弃当前批次则单独发送“取消这批”。
- 某条内容只想聊天时，在这条消息中明确写“只聊不记”。它不会进入长期记忆、日记或事件追问，但这不等于删除普通会话记录，也不会撤回已经发给云端的内容。
- 图片判断和语音转写可能出错。涉及事实的整理需要你确认；识别失败或附件缺失时，按失败提示补充说明。

## 记忆和主动联系

在“记忆与隐私偏好”查看保存内容和原始来源，点击“确认／纠正”修改事实；“撤回记忆”使该条不再被召回，但保留原始来源，不删除原对话。

允许主动联系后，系统在页面显示的六个时间窗口内尝试联系，默认安静时段 23:00—10:00，每天最多 6 次、每周最多 42 次；这些是上限，不是承诺发送次数。事件追问针对你自己的未解决事件，同一事件每天最多问一次。可以明确要求改期、取消，或说“等我有结果再说”；不要回复也不会被当成事情已完成。

需要暂时安静时，勾选“暂停后台整理和主动联系”并保存。当前版本同时停用自动简报，但不停止普通聊天；取消暂停后，要重新检查简报预览并启用简报。需要冻结整个账号时联系运营者。撤回云端处理同意后，微信助手会停用；再次使用时需重新允许云端处理并启动助手。

## 资料 用量和账号维护

“我的知识库与人设”可加载和编辑自己的笔记。修改已有内容前先从列表加载；SOUL.md 用于调整说话风格。点击“导出我的资料”可下载自己的资料、可读历史和设置，不包含账号密钥；请妥善保存导出文件。

“刷新用量”显示本人请求记录。费用是估算值，待核对或空白不代表免费。内测暂不设金额硬上限，模型并发和工具循环仍有限制。

你的空间与其他测试者隔离，但运营者和宿主机管理员仍有管理数据的能力；这不是只有你能解密的保险箱。当前使用家用电脑提供服务，关机、休眠或断网会影响访问。计划维护会由运营者安排；更新程序不应覆盖个人资料或人设。停用账号先冻结并保留导出机会，删除需另行联系运营者。

## 和运营者一起完成的真实验收

以下项目需要你实际操作，不能用“服务启动了”代替。首次测试请使用虚构、无敏感内容的例子。

| 项目 | 你需要确认的结果 |
|---|---|
| 远程开通 | 手机流量或异地网络能打开个人网址、登录和保存设置 |
| 微信 | 文字、图片、语音分别获得正确回复；记日记后能在本人资料中找到记录 |
| 邮件 | 验证码和测试邮件确实到达；预览与实际简报可核对 |
| 记忆 | 能查看来源，纠正后不再召回旧结论，撤回后不再召回 |
| 主动联系 | 同意后收到一次实际到时联系；回复、改期、暂停和取消符合预期 |
| 导出和维护 | 导出只含本人资料；一次约定维护后仍能登录并找到原资料 |

运营者逐项记录日期和结果；未实际完成的项目保持待验收。完整部署状态见[验收报告](pilot-validation.md)。
